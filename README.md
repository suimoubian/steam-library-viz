# 基于个人游戏库行为数据的消费决策可视化与人机交互

## 在线演示说明

这是**纯静态演示版**，可以直接放在任何静态托管上（GitHub Pages /
Cloudflare Pages / Netlify / Vercel）。打开 `index.html` 即可，无需任何后端。

## 包含什么

```
index.html                完整演示页面（约 6 MB，数据全部内嵌）
lib/echarts.min.js        图表库（本地化，不走 CDN）
lib/bootstrap.min.css     样式库（本地化，不走 CDN）
.nojekyll                 GitHub Pages 用：跳过 Jekyll 处理
404.html                  找不到页面时的提示
README.md                 本文件
```

**没有任何外部资源依赖**：断网、离线打开都能完整运行。

## 隐私说明（重要）

这个版本**只有前端**，但功能是完整的：

| 功能 | 线上是否可用 | 说明 |
|---|---|---|
| 11 个分析视图（C1–C11） | 可用 | 数据内嵌在 `index.html` 里 |
| 22 位参与者的筛选 | 可用 | 同上 |
| 年度报告 / EXPORT 导出 PNG | 可用 | 纯前端实现 |
| **在线获取**（输 API Key + SteamID 抓取） | **可用** | 经 Cloudflare Worker 代理调用 Steam 接口 |
| 导入 / 粘贴 / 拖拽自己的数据 | 可用 | 纯前端，数据只存浏览器 |
| 「我的数据」本地版 | 不可用 | 那是本机才有的路径，线上用「在线获取」替代 |

**线上页面不会收集、上传、上报任何数据**：没有埋点、没有统计脚本、
没有第三方 SDK；所有计算都在浏览器里完成。页面右下角显示
`OFFLINE · 内嵌数据` 徽章，表示当前使用内嵌数据集。

**API Key 去哪里了**：只从你的浏览器直接发给 Steam（经代理转发），
代理**不记录、不存储**。Key 也不会写进 localStorage。
用户的游戏库数据只存在自己浏览器的 IndexedDB 里。

**为什么要一个代理**：Steam 的所有接口都不返回 `Access-Control-Allow-Origin`，
浏览器无法直连。代理代码在提交包的 `源码/04_云端代理/worker.js`。

## 数据来源

- 22 位知情同意的参与者，共 785 条游戏记录 / 395 款游戏
- 采集时间：2026-10-09
- 已脱敏：不含 SteamID64、不含头像、不含任何可识别信息
- 指标口径见论文第 3 章
